# ConjurePR Installation Guide

> Recommended deployment for unattended or long-running ConjurePR use.

This guide installs ConjurePR as a dedicated, unprivileged Linux service account. ConjurePR clones approved remote repositories into its own private workspace and never requires access to the operator's existing working copies.

Follow the complete, ordered guide in [docs/install/00-index.md](docs/install/00-index.md). The detailed guide is modular so each installation step can be read independently.

For a faster evaluation setup, see [QUICKSTART.md](QUICKSTART.md).
