# Requirements

You need:

- Linux with systemd;
- Python 3.11 or newer;
- Git;
- GitHub CLI or another supported GitHub authentication method;
- access to an OpenAI-compatible LLM endpoint;
- administrator access for initial installation;
- one or more GitHub repositories approved for ConjurePR use.

Check:

```bash
python3 --version
git --version
gh --version
systemctl --version
```
