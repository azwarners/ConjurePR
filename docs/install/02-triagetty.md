# Optional setup companion: TriageTTY

ConjurePR can be installed by following this guide directly.

Users who prefer interactive help may use TriageTTY as a setup companion.

From the ConjurePR repository:

```bash
cat INSTALL.md
```

Then ask TriageTTY:

> Help me configure ConjurePR on this machine.

TriageTTY can help:

- explain unfamiliar steps;
- prepare the next command;
- interpret command output;
- troubleshoot failures;
- verify permissions and service status.

The user remains in control of every command that is executed.

TriageTTY is optional. ConjurePR does not depend on it.
